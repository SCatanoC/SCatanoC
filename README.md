## 👨‍💻 About Me

I am an **Information Engineer** and **Technologist in IT Systems Development** from the
<a href="https://www.iue.edu.co/">Institución Universitaria de Envigado</a>.

I currently work as a **Full-Stack Developer**, building and maintaining production web platforms with a strong focus on **Next.js, React, TypeScript, PostgreSQL, and Supabase**.

My experience includes designing and developing complete application features across the stack, including **database architecture, APIs, authentication, data processing, dashboards, reporting systems, file imports, and business logic**.

I also have experience coordinating development work and supporting other developers, which has strengthened my skills in **technical decision-making, code organization, debugging, and software architecture**.

I enjoy working on systems that solve real business problems and continuously improving their performance, maintainability, security, and usability.
